# Freelance Marketplace – Frontend

## About the Project
The frontend of the Freelance Marketplace is built using React and Vite. It provides an interactive interface where users can explore freelance services and access marketplace features.

## Technologies Used
- React.js
- Vite
- JavaScript
- CSS / Tailwind CSS (as configured in the project)
- Axios (if used for API requests)

## Features
- User Registration
- User Login
- Responsive Navigation Bar
- Dashboard Interface
- Freelance Marketplace UI
- API Integration with Backend

## Installation and Setup

### 1. Navigate to Frontend
```bash
cd frontend
```

### 2. Install Dependencies
```bash
npm install
```

### 3. Run the Development Server
```bash
npm run dev
```

Open the local URL shown in the terminal.

## Build for Production
```bash
npm run build
```

## Deployment
The frontend can be deployed using Netlify or Vercel.

## Backend
The backend source code and setup instructions are available in the `../backend` folder.
